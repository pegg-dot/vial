# ADR 0001: Web first, native later

## Status

Accepted

## Context

The product needs indexable catalog pages, shareable entity URLs, rapid visual iteration, and an acquisition surface before it needs native-only features.

## Decision

Build the first product in Next.js. Defer SwiftUI until watchlists, alerts, or scanning demonstrate a clear retention advantage.

## Consequences

- One primary codebase for early validation
- Better discovery and sharing
- Faster product iteration
- Native push and scanning remain deferred
