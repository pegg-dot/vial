# ADR 0004: No universal safety score

## Status

Accepted

## Context

Identity, quantity, impurity, sterility, endotoxin, sampling, laboratory competence, and legal status answer different questions.

## Decision

Present evidence as separate dimensions with established, partial, or unknown states. Do not publish a universal `safe` or `quality` score.

## Consequences

- More honest communication
- Slightly more interface complexity
- Better support for corrections and new evidence
