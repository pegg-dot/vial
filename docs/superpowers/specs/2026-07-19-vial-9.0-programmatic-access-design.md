# VIAL 9.0 — Programmatic Access + Exports

**Status:** approved (Nate delegated the slice) · 2026-07-19 · base = 8.0 tip (5d9dfa5)
**Slice of "enterprise platform":** #1 programmatic access + #2 exports. The other
subsystems (research terminal, risk products, lab software) become later releases.

## Thesis

Externalize the published evidence graph as a product. Third parties get scoped,
rate-limited, bearer-authenticated **read** access to *published* (review-gated)
data, plus bounded exports. Mirrors the existing seller/lab hashed-token pattern.

## Boundary

Published projections only — no commerce, no PII, no other users' records, read-only.
Keys are hashed at rest, revealed once, scoped, revocable, and expirable. Rate-limited
per key via the existing DB limiter.

## Scope

**Migration 11 (schema v11) — `api_keys`**: id, owner_user_id (FK auth_users),
name, key_prefix, key_hash (UNIQUE), scopes jsonb, status (active|revoked),
created_at, last_used_at, expires_at (nullable). Index on key_hash.

**`src/server/api-access/`**
- `keys.ts` — createApiKey({ownerId,name,scopes,expiresAt?}) → returns plaintext
  ONCE (`vial_pk_<base64url>`) + prefix; listApiKeys(ownerId); revokeApiKey(ownerId,id)
  (owner-scoped); resolveApiKey(plaintext) → {id,ownerId,scopes} | null (sha256 hash
  lookup, active + not expired, bumps last_used_at).
- `bearer.ts` — `requireApiKey(request, scope)` → {access:{ownerId,scopes,keyId}} |
  {response}: parse Authorization: Bearer, resolve, scope-check (403), rate-limit
  (bucket "public-api", key=keyId, 120/60s → 429), else 401.
- `csv.ts` — `toCsv(rows, columns)` with correct escaping (comma/quote/newline).

**Public API `/api/public/v1/*`** (bearer, no session)
- `GET me` — echoes the key's owner + scopes (auth smoke for clients).
- `GET catalog` (scope `market:read`) — published catalog projection.
- `GET signals` (scope `signals:read`) — published opportunity signals.
- `GET market-summary` (scope `market:read`) — aggregate market data.
- `GET export?dataset=catalog|signals&format=csv|json` (scope `export:read`) —
  bounded (row cap) export; CSV via `toCsv`.

**Perimeter**: add `/api/public/` to the deny-by-default public-API prefix (bearer,
not session) so requests reach the per-route `requireApiKey` guard.

**OpenAPI**: extend `/api/openapi.json` with the public paths + a bearer security
scheme.

**UI — `/account/developer`** (customer/seller, session-gated): create key
(reveal-once), list keys (prefix + scopes + last-used + status), revoke, a copy-ready
curl example, and a link to the OpenAPI contract.
