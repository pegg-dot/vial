# VialGrade 9.x — Enterprise Completion (remaining slices)

**Status:** approved (Nate: "do the rest of this step") · 2026-07-21 · base = 9.0 + csv fix (fceff55)
Completes the 5-subsystem "enterprise platform" begun in 9.0 (#1 access + #2 exports).

## Slice A — Risk-signal feeds

Package the existing opportunity-signal engine as a filterable, bearer-authenticated
feed product. Builds on 9.0's API-key layer.

- New scope `feeds:read` (added to `API_SCOPES`).
- `src/server/api-access/feeds.ts` — pure `filterRiskSignals(signals, {types?, minScore?})`
  → ranked subset (score desc). No new table; feeds are filtered pulls.
- `GET /api/public/v1/feeds` (scope `feeds:read`): params `type` (comma list),
  `minScore`, `format` (json|csv), `limit` (≤100). Published signals only.
- Developer page lists the new scope + feed example.

## Slice B — Research terminal

A dense, session-gated power-user console composing existing published readers — no
new backend. Route `/terminal` (customer/seller).

- Panels: command search (links to /search), live risk signals (getPublicSignals),
  reviewed-change ledger (getPublications), top price movers (catalog), watchlist
  count. Monospace/terminal accent within VialGrade's palette; keyboard hint.

## Slice C — Laboratory operations analytics

Lab-gated operations surface over the evidence network. Route `/lab/analytics`
(laboratory account).

- `getLaboratoryAnalytics(laboratoryId)` in evidence-network/repository: aggregates —
  report throughput (issued/revoked), test-order status mix, sample count, custody-
  event integrity (chains verified), method coverage, open evidence conflicts.
- Page renders the aggregates as a lab ops dashboard.

## Testing

- Unit: `filterRiskSignals` (type filter, minScore, ranking, limit).
- Integration: `/api/public/v1/feeds` via bearer returns filtered signals; wrong scope
  → 403. `getLaboratoryAnalytics` returns real aggregates for a seeded lab.
- Live smoke: curl the feeds endpoint with a `feeds:read` key; render /terminal and
  /lab/analytics (screenshot).

## Out of scope

Saved/named feeds + webhook delivery (later); real-time streaming; the terminal's
inline editing (read-only console for now).
